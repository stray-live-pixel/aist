## Quick install

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/stray-live-pixel/aist/main/scripts/install-from-github.sh)
```

After installation, open the **aist** Activity Bar item, create a chat, choose a model, and ask a question.
