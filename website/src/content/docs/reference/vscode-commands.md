---
title: VS Code commands
description: Commands contributed by AIST.
---

| Command                        | Purpose                                                    |
| ------------------------------ | ---------------------------------------------------------- |
| **aist: Open Chat**            | Open the sidebar chat view.                                |
| **aist: New Chat**             | Create a new chat.                                         |
| **aist: Show Chats**           | Show chats.                                                |
| **aist: Open Chat in Editor**  | Open the current or selected chat as an editor panel.      |
| **aist: Settings**             | Open AIST settings.                                        |
| **aist: Autonomous Runner**    | Open the autonomous runner dashboard.                      |
| **aist: Open AIST Storage**    | Open workspace `.aist-agent` storage.                      |
| **aist: Edit Selection**       | Transform the current selection with the configured model. |
| **aist: Show Logs**            | Open extension logs.                                       |
| **aist: Login ChatGPT Codex**  | Start Codex authorization.                                 |
| **aist: Logout ChatGPT Codex** | Disconnect Codex authorization.                            |
