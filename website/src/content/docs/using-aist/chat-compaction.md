---
title: Chat compaction
description: Keep long conversations manageable.
---

AIST can summarize a long chat into a new handoff chat.

The summary preserves:

- goals;
- decisions;
- constraints;
- changed files;
- commands that were run;
- current status;
- open tasks;
- important errors.

Compaction can run automatically when enabled and context usage reaches the configured threshold, or manually from the chat UI.
