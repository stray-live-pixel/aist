---
title: Chat workflow
description: How to work with AIST chats.
---

AIST chats live in the VS Code sidebar and can also be opened in editor panels.

Typical workflow:

1. Open **aist** from the Activity Bar or run **aist: Open Chat**.
2. Create a chat with **aist: New Chat**.
3. Select a model.
4. Ask a question or request a change.
5. Watch tool calls as they appear in the chat.
6. Approve or deny risky actions.

While a request is running, the composer shows current activity. You can stop the request; pending approvals are denied and the model request is aborted.

Chats can be selected, duplicated, deleted when idle, opened in editor panels, and compacted when they become long.
