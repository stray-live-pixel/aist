## Быстрая установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/stray-live-pixel/aist/main/scripts/install-from-github.sh)
```

После установки откройте **aist** в Activity Bar, создайте чат, выберите модель и задайте вопрос.
