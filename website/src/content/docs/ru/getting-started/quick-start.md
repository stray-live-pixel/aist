---
title: Быстрый старт
description: Первый запрос в AIST.
---

1. Откройте **aist** в Activity Bar.
2. Создайте или выберите чат.
3. Выберите модель в composer.
4. При необходимости откройте файл или выделите код.
5. Отправьте вопрос.
6. Следите за tool calls и подтверждайте рискованные действия.

AIST автоматически добавляет контекст редактора: выделенный код или содержимое активного файла в пределах лимита.
