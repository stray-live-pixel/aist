title: Команды VS Code
description: Команды, которые добавляет AIST.
---

| Команда                        | Назначение                            |
| ------------------------------ | ------------------------------------- |
| **aist: Open Chat**            | Открыть chat view.                    |
| **aist: New Chat**             | Создать новый чат.                    |
| **aist: Show Chats**           | Показать чаты.                        |
| **aist: Open Chat in Editor**  | Открыть чат в editor panel.           |
| **aist: Settings**             | Открыть настройки AIST.               |
| **aist: Autonomous Runner**    | Открыть dashboard автономного runner. |
| **aist: Open AIST Storage**    | Открыть `.aist-agent`.                |
| **aist: Edit Selection**       | Изменить выделение через модель.      |
| **aist: Show Logs**            | Открыть логи расширения.              |
| **aist: Login ChatGPT Codex**  | Авторизоваться в Codex.               |
| **aist: Logout ChatGPT Codex** | Выйти из Codex.                       |
