## OpenRouter

Сохраните API key:

```bash
aist auth openrouter set-key
```

Или используйте переменную окружения:

```bash
export OPENROUTER_API_KEY=sk-or-...
```

## ChatGPT Codex

Команды VS Code:

- **aist: Login ChatGPT Codex**;
- **aist: Logout ChatGPT Codex**.

Codex model IDs используют префикс `codex:`.
