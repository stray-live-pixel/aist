---
title: Изменения файлов и подтверждения
description: Как AIST делает изменения проверяемыми.
---

AIST может предлагать изменения файлов, но mutating tools по умолчанию требуют подтверждения.

Перед записью открывается нативный diff-preview VS Code:

- `write_file` показывает полный целевой content;
- `replace_in_file` показывает replacement;

Вы можете проверить diff, поправить правую сторону и подтвердить только готовый вариант.
