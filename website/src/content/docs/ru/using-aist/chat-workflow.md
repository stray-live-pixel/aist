---
title: Работа с чатом
description: Как пользоваться чатами AIST.
---

AIST работает в sidebar VS Code и может открывать чаты в editor panels.

Обычный сценарий:

1. Откройте **aist** из Activity Bar или командой **aist: Open Chat**.
2. Создайте чат через **aist: New Chat**.
3. Выберите модель.
4. Задайте вопрос или попросите изменить код.
5. Следите за инструментами в чате.
6. Подтверждайте или отклоняйте рискованные действия.

Запрос можно остановить: pending approvals будут отклонены, а model request — прерван.
