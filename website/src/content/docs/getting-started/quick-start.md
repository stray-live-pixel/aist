---
title: Quick start
description: Send your first request to AIST.
---

1. Open the **aist** Activity Bar item.
2. Create or select a chat.
3. Choose a model in the composer.
4. Optionally open a relevant file or select code in the editor.
5. Ask a question.
6. Review tool activity and approve risky actions when AIST asks.

AIST automatically attaches editor context. If text is selected, that selection is sent. Otherwise AIST can send the active file content up to the configured limit.
