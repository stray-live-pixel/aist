---
title: What is AIST?
description: A short overview of the AIST VS Code extension.
---

AIST is a VS Code extension that adds a coding-agent chat to your editor.

It can:

- discuss selected code or the active file;
- search and read files in the current workspace;
- run focused Bash commands when you approve them;
- edit files through VS Code diff previews;
- use OpenRouter models or ChatGPT Codex models;
- remember project instructions, custom modes, and custom skills.

AIST is designed for day-to-day coding help: explaining code, making small edits, running checks, preparing refactors, and keeping you in control of risky actions.
