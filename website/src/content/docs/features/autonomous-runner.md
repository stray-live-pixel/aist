---
title: Autonomous Runner
description: Run predefined flows and batches from the AIST dashboard.
---

Autonomous Runner executes predefined flows and runs from the shared AIST backend.

It can:

- show available flows and runs;
- run dry-run validation;
- select execution engines;
- monitor sessions and event tails;
- stop running sessions;
- reveal session folders;
- export session output as Markdown or JSON.

Use dry-run first when validating definitions. Autonomous Runner has separate controllers, stop commands, storage, and error handling from the chat agent.
