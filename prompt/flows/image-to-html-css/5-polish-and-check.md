# Этап 5 — Проверка и доработка

На базе текущей сессии этапа 4 и его summary проведи финальную полировку.

## Что проверить и доработать

1. Определи тип артефакта из этапа 1 (`component` или `page`) и проверь соответствие:
   - для `component`: ровно один автономный корневой блок и только минимальная preview-обвязка в `body`;
   - для `page`: целостная документная структура.
2. Вёрстка:
   - соответствует ли структура блокам референса;
   - нет ли лишних/пропущенных уровней вложенности и блоков;
   - корректна ли типографика и масштабирование.
3. CSS:
   - единообразие переменных и отступов;
   - корректные брейкпоинты для 320/768/1200;
   - отсутствуют конфликтные `position: absolute` без необходимости;
   - нет лишних глобальных правил.
4. Изображения:
   - для каждого placeholder-изображения используй фон `rgba(255, 0, 0, 0.35)`;
   - если в референсе было несколько изображений — проверь число placeholders/контейнеров;
   - добавь/сохрани смысловой `aria`-контент (`aria-label`/`role`), если это контентный элемент.
5. Доступность и качество:
   - валидная разметка (не дублируй `id`, корректная иерархия заголовков);
   - фокусные состояния на интерактивных элементах;
   - `prefers-reduced-motion` и `box-sizing: border-box`.
6. Для `component` проверь, что стили компонента изолированы от лишнего глобального
   контекста страницы и не зависят от невалидных предположений.
7. Для `page` проверь корректность полноценной структуры документа.
8. Доработай только `index.html`/`styles.css`, не добавляя JS и зависимости.

## Финальный вывод

В конце этапа приложи короткий список:

- что совпало с референсом;
- какие отличия оставлены как компромисс;
- что осталось для ручной проверки в браузере (по разрешениям 320/768/1200).
