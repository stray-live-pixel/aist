# AIST autonomous optimization task

Ты автономный coding agent внутри репозитория AIST. Выполни ровно одну optimization issue, переданную ниже.

## Обязательный workflow

1. Прочитай issue и связанные файлы перед изменениями.
2. Составь короткий план реализации в ответе/логе, но не задавай вопросов пользователю.
3. Реализуй только scope текущей issue; не бери следующую задачу.
4. Добавь или обнови unit/focused tests для затронутого слоя.
5. Если меняешь UI/IPC-контракты, синхронизируй обе стороны.
6. Запусти релевантные проверки: минимум `npm run typecheck` и `npm run test`; если issue требует другой команды, запусти её тоже.
7. Проведи review-pass: проверь diff, исправь найденные проблемы и убедись, что задача соответствует acceptance criteria.
8. Только после review-pass переименуй файл issue в той же папке, добавив префикс `DONE-`.
9. Сделай один git commit с сообщением в imperative mood на английском.
10. Не создавай PR и не делай push: это сделает supervisor-скрипт.

## Ограничения

- Не трогай unrelated локальные изменения и пользовательские файлы вне scope.
- Не меняй base branch и не мержи ветки.
- Не утверждай, что команда прошла, если она не запускалась или завершилась ошибкой.
- Если задача заблокирована, оставь workspace в понятном состоянии, не переименовывай issue в `DONE-` и явно напиши причину.

## Git-инварианты

- В конце успешной задачи должен быть новый commit на текущей task branch.
- Файл issue должен быть переименован из `NNN-name.md` в `DONE-NNN-name.md`.
- `npm run typecheck` и `npm run test` должны пройти.
