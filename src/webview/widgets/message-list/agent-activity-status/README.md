# AgentActivityStatus

Строка состояния текущей работы агента внизу истории сообщений.

## Состав

- `AgentActivityStatus.tsx` — React-компонент.
- `AgentActivityStatus.module.scss` — локальные стили без Tailwind.
- `types.ts` — публичные props.
- `utils.ts` — форматирование статусов и fallback-текста.
- `AgentActivityStatus.stories.tsx` — Storybook-сценарии.
