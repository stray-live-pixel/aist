# outline_file

`outline_file` — будущий fs-инструмент для быстрого обзора структуры одного файла без чтения всего содержимого.

## Идея

Инструмент должен возвращать компактный список значимых символов файла: классы, функции, методы, интерфейсы, типы, константы и другие сущности, которые поддерживает язык файла.

Главная задача — помочь агенту понять карту файла перед точечным чтением или редактированием:

- какие публичные сущности есть в файле;
- где они расположены по строкам;
- какая вложенность у методов и дочерних символов;
- какой фрагмент можно точечно прочитать через `read_file_range`, если агент уже уверен, что полного файла не нужно.

## Ожидаемый контракт

Входные аргументы должны передаваться объектом:

```ts
{
  reason: string;
  nextStep?: string;
  path: string;
  maxSymbols?: number;
  includeChildren?: boolean;
}
```

Ожидаемый успешный результат:

```ts
{
  ok: true;
  path: string;
  language?: string;
  symbols: Array<{
    name: string;
    kind: string;
    startLine: number;
    endLine: number;
    children?: unknown[];
  }>;
  truncated: boolean;
}
```

## Как должна работать реализация

1. Проверить, что `path` — workspace-relative путь и файл находится внутри workspace.
2. Определить язык файла по расширению или adapter-слою редактора.
3. Получить document symbols через host capability VS Code или отдельный parser-adapter.
4. Нормализовать результат в стабильный JSON-контракт, не зависящий от VS Code API.
5. Ограничить размер ответа через `maxSymbols`, чтобы не раздувать контекст модели.

## Важные ограничения

- Сейчас runtime-инструмент удалён намеренно: legacy fallback возвращал `unsupported` и не давал полезной информации агенту.
- Новая реализация не должна жить в `features/filesystem-tools` inline-кодом.
- Будущий код должен находиться рядом с этим README в `src/core/tools/fs/outline_file`.
- Общие fs-утилиты нужно переиспользовать из `src/core/tools/fs/shared`.
- Если появятся общие formatter/parser helper-ы для нескольких инструментов, их нужно вынести в `src/core/tools/shared` или доменный `shared`.
- Каждая функция должна принимать аргументы объектом и быть достаточно короткой, чтобы её легко проверял младший разработчик.
