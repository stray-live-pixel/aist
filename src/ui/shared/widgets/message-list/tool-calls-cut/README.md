# ToolCallsCut

Сворачиваемый блок tool-call сообщений, относящихся к одному пользовательскому запросу.

## Состав

- `ToolCallsCut.tsx` — React-компонент и локальный заголовок блока.
- `ToolCallsCut.module.scss` — локальные стили без Tailwind.
- `types.ts` — публичные props и внутренние props заголовка.
- `utils.ts` — форматирование количества инструментов и длительности.
- `ToolCallsCut.stories.tsx` — Storybook-сценарии.
