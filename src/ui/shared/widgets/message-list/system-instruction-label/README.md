# SystemInstructionLabel

Sticky-кнопка активных системных инструкций в начале чата. Открывает модальное окно настроек режимов и пресетов.

## Состав

- `SystemInstructionLabel.tsx` — React-компонент и dialog через portal.
- `SystemInstructionLabel.module.scss` — локальные стили без Tailwind.
- `types.ts` — публичные props и props dialog.
- `utils.ts` — chips, fallback-источники и обрезка подписей.
- `SystemInstructionLabel.stories.tsx` — Storybook-сценарий.
