# message-list

Виджет истории сообщений чата и связанные компоненты.

## Структура

Каждый компонент живёт в отдельной папке:

- `message-list/` — основной список сообщений.
- `agent-activity-status/` — статус текущей работы агента.
- `empty-state/` — пустое состояние истории.
- `system-instruction-label/` — sticky-кнопка активных системных инструкций.
- `tool-calls-cut/` — сворачиваемая группа tool-call сообщений.

У каждой папки есть `tsx`, `module.scss`, `index.ts`, `types.ts`, `README.md` и Storybook-файл. `utils.ts` добавлен там, где есть нетривиальная логика.
