# Flow: image-to-html-css

Запусти так:

```
./claude-auto.sh --flow image-to-html-css "source: ./assets/my-mockup.png"
```

Если референс приходит как описание, передай это в `extra prompt`.

Цель:

1. зафиксировать структуру и стили референса;
2. определить, это страница или изолированный компонент;
3. создать единый файл спецификации `image-spec.md` с детальным разбором референса;
4. создать рабочий `index.html` и `styles.css` в текущей папке проекта;
5. проверить визуальную и семантическую корректность итогового результата.

Важно:

- этапы 1–3 обязаны создавать и обновлять `image-spec.md`;
- этап 4 обязан сначала прочитать `image-spec.md`, а затем уже собирать верстку.

Обязательное правило для изображений: если в референсе есть фото/иллюстрации/вставки,
в итоговом артефакте вместо внешних ассетов используй placeholders с
полупрозрачным красным фоном (`rgba(255, 0, 0, 0.35)`).
