# Этап 4 — Реализация `index.html` и `styles.css`

На основе анализа и уточнений этапов 1-3:

1. сначала открой `image-spec.md`;
2. затем открой исходник/референс (по `extra prompt`, например `source: ./...`);
3. собери `index.html` и `styles.css` максимально близко к референсу.
   Определи режим по анализу:

- `mode: component` — изолированный блок, с минимальной оболочкой для standalone-рендера;
- `mode: page` — полноценная страница.

## Обязательные требования

1. Создай/обнови ровно два файла:
   - `index.html`
   - `styles.css`
2. В `index.html` должна быть только структура и подключение стилей:
   - `<link rel="stylesheet" href="styles.css">`
3. Все стили вынеси в `styles.css`. Запрещены inline-стили, JS-стилизации и
   сторонние зависимости.
4. Если `mode: component`:
   - оберни компонент в один корневой `.component` (или явно названный) блок;
   - не добавляй визуальные секции страницы (`header`, `main`, `footer`), если они не в референсе;
   - оставь только минимальную рамочную обвязку для живого preview (центровка/паддинги можно задать на обёртке `body`, но не на сам компонент).
     Если `mode: page`:
   - используй полноценную семантичную разметку страницы.
5. Везде, где это возможно, используйте семантичную разметку:
   - правильные контейнеры/контейнеры секций;
   - логические `h1`…`h6`, списки и текстовые иерархии.
6. Любое место с предполагаемой картинкой/фото/обложкой реализуй как placeholder:
   - в `html` это один элемент с классом вроде `.image-placeholder`;
   - в `css` фон `rgba(255, 0, 0, 0.35)` (полупрозрачный красный);
   - задавай понятные размеры блока (например `aspect-ratio`) и текст/лейбл "Image placeholder";
   - не использовать внешние `img src`, `url()` и base64-ресурсы.
7. Задай адаптивное поведение (минимум: 320/768/1200).
8. Используй CSS-переменные для ключевых значений:
   - цвета, размеры, радиусы, тени, отступы.
9. Добавь базовую доступность:
   - `lang` в `<html>`,
   - понятные `aria-label` там, где это нужно,
   - контраст текста минимум на уровне базовых требований.
10. Если источник содержит графику/логотипы:

- воссоздай их через placeholder с полупрозрачным красным фоном;
- не тянь внешние ресурсы.

## Формат

- Держи визуальные решения фактическими по списку из этапа 1.
- Если это компонент, не допускай утечку стилей наружу (чёткая граница между
  стилизацией компонента и preview-обвязкой).
- Не добавляй JavaScript-код, если это не указано в референсе явно.
- После выполнения итоговые изменения должны выглядеть как автономный frontend.

## Как считать этап завершённым

- `index.html` и `styles.css` существуют, открываются и отображают одну страницу,
  визуально соответствующую описанию референса.
