# Этап 3 — Проверка и уточнение (автономно)

Запусти как автономный проход без `--resume` от прошлого чата:
воспринимай вход как `summary` из этапа 2, затем открой `image-spec.md`
и повторно проверь картинку/референс для финального дооформления спеки.
Если находишь уточнения, применяй их в `image-spec.md`.

## Что сделать

1. Проверь, не пропущены ли детали, которые не попали в итог этапа 2.
2. Отметь все оставшиеся неясные зоны и зафиксируй новые предположения.
3. Сверь список изображений/placeholder-зон с предыдущими выводами:
   - есть ли расхождения в количестве;
   - есть ли расхождения в приоритетах/размере;
   - есть ли расхождения по назначению.
4. Перепроверь итоговый выбор режима:
   - `component` или `page`;
   - где должна начинаться и заканчиваться компонентная область.
5. Сформируй финальную доработку анализа:
   - что нужно изменить по сравнению с этапом 2;
   - что добавляется/исправляется;
   - какие решения оставляются как компромисс.
6. Обнови `image-spec.md`:
   - зафиксируй финальную структуру всех блоков;
   - обнови блок по изображениям/placeholder;
   - зафиксируй финальное решение по `mode` и оставшимся рискам.

## Формат ответа

- короткий список уточнений и рисков по каждому спорному блоку;
- итоговое `mode` (`component` или `page`);
- итоговый перечень placeholder-зон с рекомендованными размерами;
- **Блок `Итоговый доработанный анализ`**, применимый в следующем этапе сборки.
- В конце укажи, что было записано в `image-spec.md`.
