# Этап 4 — Самопроверка

С полным контекстом реализации: сделай критическое code review файла
`mini-gta/game.html`. Изменения в этом этапе **не вносить** — только список
наблюдений.

## Что проверить

1. **Загрузка и Three.js**: корректный import map/CDN, нет syntax errors,
   `init()` вызывается, resize работает.
2. **3D-рендер**: сцена не пустая, камера смотрит на игрока, город читается,
   дороги/здания/трамплины/банкоматы/звёзды видны.
3. **Управление машиной**: скорости комфортные, поворот контролируемый,
   торможение работает, трамплины не выбрасывают машину за сцену.
4. **Трафик**: NPC-машины движутся, не стоят все в одной точке, не разгоняются
   бесконечно, не ломают управление игрока.
5. **Пеший режим**: вход/выход по `E` работает, персонаж появляется рядом с
   машиной, можно вернуться в машину, камера корректно переключается.
6. **Банкоматы**: можно взаимодействовать только пешком и рядом, один банкомат
   нельзя бесконечно грабить без ограничения, score обновляется.
7. **Полиция**: розыск стартует после банкомата, полиция преследует актуальную
   цель, wanted stars отображаются, сбор звёзд снижает розыск до 0.
8. **Производительность**: нет тяжёлых аллокаций в каждом кадре, лишних новых
   геометрий/материалов в `update`, бесконечного роста массивов.
9. **Чистота кода**: дубли, мёртвые функции, неиспользуемые переменные, слишком
   длинные функции, магические числа.

## Формат отчёта

Список пронумерованных пунктов, каждый: проблема (1 строка) + предлагаемая
правка (1–2 строки). Без дисклеймеров и общих фраз. Если всё хорошо — так и
напиши.
