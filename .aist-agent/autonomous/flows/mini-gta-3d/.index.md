# 3D Mini GTA flow

Цель: получить работающий `mini-gta/game.html` с небольшим 3D open-city
sandbox-прототипом в браузере. Игрок может ездить по городу, выходить из машины,
ходить пешком, прыгать с трамплинов, грабить игровые банкоматы, получать розыск
полиции и собирать звёздочки, чтобы сбросить розыск.

Игра должна быть аркадной и условной: без реалистичных инструкций по преступлениям,
без крови, без жестокости, без реальных брендов. Главное — читаемая игровая
петля и комфортное управление человеком.

Агент должен создать папку `./mini-gta/` в текущем репозитории, если её ещё нет,
и держать игровой результат внутри неё. Допустима зависимость от Three.js через
CDN/import map. Никакой сборки, package.json и дополнительных файлов.
