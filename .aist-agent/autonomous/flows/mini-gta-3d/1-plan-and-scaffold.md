# Этап 1 — План, архитектура и каркас

Спроектируй `mini-gta/game.html` для браузерного 3D open-city прототипа в духе
mini GTA. Игра должна быть простой и условной, но реально управляемой человеком.

## Главные требования

- Один файл `./mini-gta/game.html` внутри текущего репозитория. Создай папку
  `./mini-gta/`, если её нет. Внутри файла — разметка, стили и JS.
- Используй Three.js через CDN/import map. Без сборки, без npm, без package.json.
- Основная сцена: небольшой город сверху/с третьего лица:
  - сетка дорог;
  - кварталы с простыми зданиями;
  - тротуары/площадки;
  - несколько трамплинов;
  - банкоматы рядом с зданиями;
  - звёздочки для снятия розыска.
- Камера третьего лица должна следовать за машиной или персонажем.
- Управление должно быть комфортным:
  - в машине: WASD/стрелки, плавный газ/тормоз/поворот, умеренная максимальная скорость;
  - пешком: WASD/стрелки, скорость ниже машины, поворот по направлению движения;
  - `E`: войти/выйти из машины или ограбить банкомат, если рядом;
  - `R`: restart;
  - `Space`: ручник/лёгкий прыжок на трамплине или дополнительный boost только если это не ломает контроль.
- Игровые состояния:
  - `driving`;
  - `onFoot`;
  - `wanted`;
  - `gameOver` не обязателен, но restart обязателен.
- Если игрок пешком грабит банкомат, начинается розыск полиции.
- Чтобы избавиться от полиции, игрок должен собрать звёздочки. Каждая звезда
  снижает уровень розыска на 1. При 0 звёздах розыск заканчивается.

## Что создать на этом этапе

1. Создать `./mini-gta/game.html` с базовой HTML-структурой, full-viewport canvas,
   минимальным HUD и overlay подсказок.
2. Подключить Three.js через import map или module import.
3. Добавить скелет JS с явно названными функциями:
   - `init`
   - `createScene`
   - `createCity`
   - `createRoads`
   - `createBuildings`
   - `createPlayerCar`
   - `createPedestrian`
   - `createTraffic`
   - `createRamps`
   - `createAtms`
   - `createPolice`
   - `createWantedStars`
   - `setupInput`
   - `update`
   - `updateDriving`
   - `updateOnFoot`
   - `updateTraffic`
   - `updatePolice`
   - `handleInteractions`
   - `updateCamera`
   - `updateHud`
   - `restartGame`
4. В начале `<script type="module">` добавь короткий комментарий с описанием
   игровых сущностей и цикла.
5. Пока не реализуй полную механику. Допустимы только константы, пустые массивы,
   объект состояния и простая сцена-заглушка, чтобы файл загружался.

После этапа должен существовать `mini-gta/game.html`, который открывается без
синтаксических ошибок и содержит каркас будущей игры.
