# Medieval platformer flow

Цель: получить работающий `game.html` со средневековым платформером — одностраничное
приложение без зависимостей и без сборки. Открывается двойным кликом или через
локальный http-сервер, играется стрелками/WASD/Space.

Итог проверяется руками в браузере.
