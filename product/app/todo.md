Давай в папке /Users/kirilleremin/Documents/dev/ai-agent/src создадим новую папку desktop и в ней реализуем десктопное приложение на основе webview.

Вот, что важно. desktop приложение и webview расширения должны иметь идентичный интерфейс, должны использовать одни и теже компоненты.

desktop приложение разрабатываем пока только для macos.

Тут может потребоваться выносить общие визуальные компоненты в shared. Тогда можно создать папку shared/ui и там можно хранить все переиспользуемые компоненты.

В итоге у меня должен появиться скрипт в package json, который соберет готовое десктопное macos приложение с ИИ-агентом, которое будет работать аналогично расширению
