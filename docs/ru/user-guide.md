# Руководство пользователя

[English documentation](../user-guide.md)

## Открытие AIST

Расширение добавляет контейнер `aist` в Activity Bar. Внутри находится webview `Chats`.

Команды:

- `aist: Open Chat` — открыть чат в sidebar.
- `aist: New Chat` — создать новый чат.
- `aist: Open Chat in Editor` — открыть текущий или выбранный чат в editor panel.
- `aist: Settings` — открыть настройки AIST.
- `aist: Open Extension Storage` — открыть хранилище расширения на диске.
- `aist: Edit Selection` — запросить инструкцию и заменить текущее выделение ответом модели.
- `aist: Show Logs` — открыть логи расширения.
- `aist: Login ChatGPT Codex` / `aist: Logout ChatGPT Codex` — управлять авторизацией Codex.

## Работа с чатом

1. Откройте `aist` из Activity Bar или командой `aist: Open Chat`.
2. Создайте чат через `aist: New Chat` или кнопку нового чата.
3. Выберите модель в composer.
4. При необходимости выделите код или откройте файл, который нужен в контексте.
5. Отправьте запрос.
6. Следите за активностью инструментов и подтверждайте рискованные действия.

Во время выполнения запроса composer показывает текущую активность. Запрос можно остановить: pending approvals будут отклонены, а текущий model request — прерван.

## Контекст редактора

Каждый запрос автоматически получает контекст активного редактора:

- если есть выделение, отправляется выбранный код;
- если выделения нет, отправляется содержимое активного файла;
- содержимое файла ограничено `openrouterAgent.maxContextChars` (по умолчанию `12000`);
- контекст включает путь файла и VS Code language ID.

Обычно не нужно вручную вставлять содержимое файлов: откройте или выделите релевантный код перед запросом.

## Markdown-сообщения

Ответы ассистента отображаются как Markdown с поддержкой GitHub-flavored Markdown. У каждого текстового сообщения есть кнопка копирования исходного Markdown.

## Действия с чатами

Чаты можно:

- выбирать из списка;
- открывать в отдельной editor panel;
- дублировать;
- удалять, если чат не выполняется;
- сжимать вручную.

Если удаленный чат был открыт в нескольких поверхностях, AIST перенаправляет их на следующий доступный чат.

## Сжатие чата

AIST может суммировать длинный чат в новый handoff chat. Сводка сохраняет цели, решения, ограничения, измененные файлы, выполненные команды, текущий статус, открытые задачи и важные ошибки.

Сжатие бывает:

- **автоматическим**, если включено и достигнут порог контекста;
- **ручным**, по действию пользователя.

## Модели

Поддерживаются две группы провайдеров:

- **OpenRouter** — ID моделей используются как есть, например `openai/gpt-4o-mini`.
- **ChatGPT Codex** — ID моделей имеют префикс `codex:`, например `codex:gpt-5.1-codex`.

Model selector группирует OpenRouter и Codex отдельно. OpenRouter модели загружаются из OpenRouter Models API; Codex модели требуют авторизации.

## Reasoning effort

В composer и настройках доступно `reasoningEffort`:

- `auto` — не отправлять reasoning parameter;
- `low`;
- `medium`;
- `high`.

Значение отправляется в OpenRouter, если оно поддерживается выбранной моделью/провайдером.

## Оценки usage и стоимости

AIST оценивает токены и стоимость по доступным метаданным модели. UI может показывать prompt tokens, completion tokens, total tokens, примерную стоимость USD и текущий процент контекста.

Это оценки, а не гарантия биллинга.
