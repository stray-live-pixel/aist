# AIST isolated run 3a80ce77-db18-4394-92dd-d4a7f75b9d5a

## Задача

Доработать Isolated agents режим работы, чтобы при создании PR агент придумывал нормальные commit message и title для PR, а не использовал обрезанный пользовательский prompt.

## Изменения

- Добавлена генерация git metadata для isolated finalizer через auxiliary model на основе user task, финального ответа агента, `git status` и staged diff summary.
- Commit message, PR title и PR body теперь нормализуются и имеют безопасный fallback без падения финализации при ошибке модели.
- `gh pr create` получает явные `--title` и `--body`, когда metadata доступна, вместо прежнего `--fill`.
- Добавлены unit-тесты для успешной генерации, fallback-сценария и нормализации fenced JSON.
