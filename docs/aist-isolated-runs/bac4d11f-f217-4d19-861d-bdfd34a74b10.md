# Isolated run bac4d11f-f217-4d19-861d-bdfd34a74b10

## Задача

Исправить кнопку `Open standard chat` на странице isolated agents: она должна быть активна во время работы агента, чтобы пользователь мог открыть обычный чат и смотреть live-ход выполнения.

## Изменения

- Добавлен helper `shouldEnableIsolationStandardChat`, который включает кнопку при наличии `chatId` или активном статусе isolated-сессии.
- Оба экземпляра кнопки `Open standard chat` в `IsolationPage` переведены на общий helper.
- Обработчик `isolation.openChat` в extension controller вынесен в отдельный orchestrator `openIsolationChatFromController`.
- Controller теперь умеет вычислять стабильный id стандартного чата `isolation-${sessionId}`, если `chatId` ещё не доехал в summary, и обновляет daemon state перед предупреждением.
- Детали controller-логики разнесены в отдельные helpers `findIsolationSessionById` и `getIsolationStandardChatId`.
- Добавлен regression-тест на активную сессию без `chatId`.

## Проверка

- Запущено: `npx vitest run src/webview/pages/isolation/shouldEnableIsolationStandardChat.test.ts`.
- Результат: проверка не стартовала, потому что в контейнере не установлены зависимости проекта; `npx` попытался временно поставить `vitest@4.1.8`, после чего config не смог импортировать `vitest/config`.
- Полный `npm run typecheck` не запускался из-за той же проблемы с отсутствующими node_modules в isolated-контейнере.
