## Задача

Исправить удаление workflow на странице управления Workflow: после клика «Удалить» и подтверждения workflow должен удаляться из файловой системы и из интерфейса, а во время ожидания удаления кнопка должна показывать loader и быть неактивной.

## Изменения

- Добавлено pending-состояние удаления workflow в `FlowsPage`: выбранная кнопка «Удалить» показывает spinner и текст «Удаляем…», кнопки строки блокируются на время операции.
- Extension теперь отправляет в webview результат операции `autonomous.operation` для статусов `done`, `cancelled` и `error`, чтобы UI мог снять pending даже при отмене подтверждения или ошибке.
- После успешного удаления extension дополнительно отправляет свежий autonomous state в webview перед событием завершения операции, чтобы список workflow обновлялся сразу.
- Добавлены переводы `autonomous.workflows.deleting` для RU/EN.
- Добавлен regression-тест, проверяющий удаление каталога workflow из `.aist-agent/autonomous/flows`.
