# aist 0.0.5

## English

### Improvements

- Improved model select UI: fixed option overlap and added collapsible provider groups.
- Grouped OpenRouter models by provider in the model picker.
- Reworked tool approval modal UI and focused the approve action by default.
- Added approval comments to approve/deny decisions.
- Fixed approval modal reopening behavior and ensured denied tools do not execute.
- Collapsed only the related tool call after approval instead of affecting unrelated calls.
- Improved tool call cards: tool name is shown as an icon pill and collapsed reason is shown on a separate line.
- Updated agent/tool instructions to prefer direct file editing tools over shell/Python scripts for file changes.

## Русский

### Улучшения

- Улучшен UI выбора модели: исправлено наложение опций и добавлены сворачиваемые группы провайдеров.
- Модели OpenRouter сгруппированы по провайдерам в списке выбора.
- Переработан UI модального окна подтверждения инструментов; действие approve получает фокус по умолчанию.
- Комментарии подтверждения теперь передаются вместе с approve/deny.
- Исправлено повторное открытие модального окна подтверждения; отклоненные инструменты не выполняются.
- После подтверждения сворачивается только связанный tool call, а не посторонние вызовы.
- Улучшены карточки tool call: название инструмента отображается как пилюля с иконкой, reason в свернутом состоянии вынесен на отдельную строку.
- Обновлены инструкции агента/инструментов: для изменений файлов предпочтительны прямые инструменты редактирования вместо shell/Python-скриптов.
