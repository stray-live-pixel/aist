# aist 0.0.8

## English

### Improvements

- Reworked agent behavior settings: Skills, Roles, Instructions, and Presets now live in a dedicated sidebar group.
- Split Presets into a standalone settings page and added Active / Project / Global tabs for behavior sections.
- Added global custom skills alongside project skills, with project definitions overriding global ones by ID.
- Simplified the chat composer: role and preset shortcuts open behavior settings, reasoning and access controls moved to the footer, and context usage with manual compaction stays in the top composer panel.
- Removed the tools count button and the sticky instructions button from the chat surface.

## Русский

### Улучшения

- Переработаны настройки поведения агента: «Навыки», «Роли», «Инструкции» и «Пресеты» вынесены в отдельную группу бокового меню.
- Пресеты вынесены на отдельную страницу настроек, а в разделы поведения добавлены вкладки «Активные» / «Проектные» / «Глобальные».
- Добавлена поддержка глобальных пользовательских навыков вместе с проектными; проектные определения переопределяют глобальные по ID.
- Упрощён composer чата: быстрые кнопки роли и пресета открывают настройки поведения, reasoning и управление доступами перенесены вниз, а заполненность контекста и ручное сжатие остаются в верхней панели composer.
- Убраны кнопка количества инструментов и закреплённая кнопка инструкций из области чата.
