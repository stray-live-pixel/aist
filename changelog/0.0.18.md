# aist 0.0.18

## English

### Fixes

- Fixed the webview chat render loop that could crash React and hide chats after opening or refreshing a chat.
- Stabilized chat creation/index updates so newly created chats stay visible and selectable after daemon state refreshes.

## Русский

### Исправления

- Исправлен циклический render webview-чата, из-за которого React падал и история чатов переставала отображаться после открытия или refresh.
- Стабилизировано обновление индекса при создании чатов: новые чаты остаются видимыми и доступными после обновления состояния daemon.
