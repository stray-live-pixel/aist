# aist 0.0.10

## English

### Improvements

- Polished approval prompt animations and notification behavior so pending tool calls are easier to notice without interrupting the chat flow.
- Updated chat UI transitions, including smoother composer and send button states.
- Added shared text UI primitives used by the webview to keep typography consistent across screens.
- Refreshed README imagery for the current chat experience.

## Русский

### Улучшения

- Доработаны анимации модалки подтверждения и поведение уведомлений, чтобы pending tool-call было проще заметить без лишнего вмешательства в работу с чатом.
- Обновлены переходы в UI чата, включая более плавные состояния composer и кнопки отправки.
- Добавлены общие текстовые UI-примитивы webview для единообразной типографики на разных экранах.
- Обновлено изображение README под актуальный интерфейс чата.
