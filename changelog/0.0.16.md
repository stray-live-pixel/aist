# aist 0.0.16

## English

### Improvements

- Added OpenRouter API key management to Settings → Providers in the webview.
- API keys are stored per provider profile, so separate OpenRouter profiles can use different credentials.
- Added a show/hide control for the API key field and e2e coverage with a settings panel screenshot.

## Русский

### Улучшения

- Добавлено управление OpenRouter API key в webview: Settings → Providers.
- API key хранится отдельно для каждого профиля провайдера, поэтому разные OpenRouter-профили могут использовать разные ключи.
- Добавлена кнопка показать/скрыть API key и e2e-покрытие со screenshot панели настроек.
