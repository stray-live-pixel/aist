# aist 0.0.17

## English

### Improvements

- Added a memory subagent that selects relevant approved memory notes before the main agent responds.
- Added chat memory analysis that proposes reusable memory candidates for user review instead of saving them silently.
- Improved persistence of memory subagent candidates across refreshes and daemon restarts.

## Русский

### Улучшения

- Добавлен субагент памяти, который перед ответом основного агента выбирает релевантные подтверждённые заметки памяти.
- Добавлен анализ чата для предложений памяти: кандидатуры показываются пользователю и не сохраняются скрыто.
- Улучшено сохранение кандидатов субагента памяти при refresh webview и перезапуске daemon.
