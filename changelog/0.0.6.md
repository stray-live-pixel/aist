# aist 0.0.6

## English

### Improvements

- Centralized webview-to-extension IPC calls in a single action layer.
- Added a read-only AgentState context for webview pages to reduce prop drilling without introducing an external state manager.
- Updated chat and settings pages to read the current agent state from the provider.
- Kept local UI state in components while preserving the extension process as the source of truth.

## Русский

### Улучшения

- Централизованы IPC-вызовы из webview в extension в едином слое действий.
- Добавлен read-only context для AgentState, чтобы уменьшить prop drilling без внешнего state-менеджера.
- Страницы чата и настроек переведены на чтение текущего состояния агента из provider.
- Локальное UI-состояние осталось внутри компонентов, а source of truth по-прежнему находится в extension-процессе.
