## Принятые решения

- Exact old `.agent-auto-logs` format не сохраняем как primary runtime storage. Новый источник правды: `.aist-agent/autonomous/sessions`; старый формат допустим только для мигратора/export compatibility.
- Direct prompt mode не входит в минимальный flow/run MVP, но остаётся Phase 2 capability.
- Terminal monitor не переносится: VS Code React dashboard заменяет его.
- HTML snapshot не нужен для MVP live monitoring; добавить позже как export artifact, если потребуется standalone read-only report.
- `--log-file` deprecated: human-readable вывод генерируется из `events.jsonl`.

## Behavior tests before deleting `prompt/`

- Legacy и native flow discovery читают `example`, `create-edit-section`, `image-to-html-css`, `mini-gta-3d`.
- Legacy и native run discovery читают `benefits-list-analysis` и валидируют `dir/tasks/repeat`.
- Frontmatter parser покрывает scalar, multiline, list of strings, list of objects и nested multiline object fields.
- Dry-run `example` исполняет stages по порядку и пишет session events/state.
- Dry-run `create-edit-section` валидирует `continue-from` contexts.
- Dry-run `benefits-list-analysis` соблюдает repeat и не двигает failed tasks.
- CLI command builders для Claude/Codex возвращают argv-массивы без shell concat.
- Stream parsers Claude/Codex маппят assistant/thinking/tool/result/error events.
- API engines используют mocked `OpenRouterClient`/`CodexClient` и явно диагностируют unsupported resume/fork.
- React dashboard показывает definitions, sessions и event tail без обращения к `prompt/src/shared/ui`.
